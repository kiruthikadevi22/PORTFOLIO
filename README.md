# Kiruthikadevi V - Data Analyst Portfolio

A modern, responsive portfolio website showcasing data analysis skills, projects, and professional experience.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, skill bar animations, and smooth scrolling
- **Contact Integration**: Easy to update contact information and social links
- **Project Showcase**: Dedicated section for displaying your data analysis projects
- **Skills Visualization**: Animated progress bars for technical skills
- **Achievement Timeline**: Professional achievements and milestones
- **Education & Certifications**: Academic background and professional certifications

## 📁 File Structure

```
kiruthikaportfolio/
```

## 🛠️ Customization

### Personal Information
Update the following sections in `index.html`:

1. **Contact Information** (Lines 15-16):
   ```html
   <title>Your Name - Data Analyst Portfolio</title>
   ```

2. **Hero Section** (Lines 50-80):
   - Update name, title, and description
   - Add your photo if needed
   - Update social media links

3. **Contact Section** (Lines 400-450):
   - Update email, phone, and LinkedIn links

### Skills
Modify the skills section (Lines 100-200) to reflect your technical expertise:
- Add or remove skill categories
- Adjust skill percentages in the `data-width` attributes
- Update skill names to match your experience

### Projects
Update the projects section (Lines 240-340) with your actual projects:
- Replace project descriptions
- Update GitHub and demo links
- Modify technology tags

### Styling
Customize colors and fonts in `styles.css`:
- **Primary Colors**: Lines 100-120 (gradient backgrounds)
- **Fonts**: Line 10 (Google Fonts import)
- **Spacing**: Various sections for margins and padding

## 🎨 Color Scheme

The portfolio uses a modern gradient color scheme:
- **Primary**: Linear gradient from #667eea to #764ba2
- **Background**: White (#ffffff) and light gray (#f8f9fa)
- **Text**: Dark gray (#333) for headings, medium gray (#666) for body text

## 🔧 Setup Instructions

1. **Download Files**: Save all files to a folder on your computer
2. **Open in Browser**: Double-click `index.html` to view in your web browser
3. **Edit Content**: Modify the HTML file to update your information
4. **Deploy**: Upload files to any web hosting service (GitHub Pages, Netlify, Vercel, etc.)

## 🌐 Deployment Options

### GitHub Pages
1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select source branch (usually `main`)
5. Your portfolio will be available at `username.github.io/repository-name`

### Netlify
1. Drag and drop your portfolio folder to [Netlify](https://netlify.com)
2. Get instant hosting with custom domain options

### Vercel
1. Import your project on [Vercel](https://vercel.com)
2. Connect your GitHub repository for automatic deployments

## 📊 Analytics Integration

To track portfolio performance, add Google Analytics:

1. Get your GA4 tracking code
2. Add the code to the `<head>` section of `index.html`
3. Monitor visitor analytics in Google Analytics dashboard
